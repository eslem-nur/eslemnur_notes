# Güvenlik Politikası

## Sorumlulukla Bildirim

Güvenlik açıklarını bildirmek için lütfen:
1. **GitHub Security Advisory** formunu kullanın
2. Veya doğrudan bana e-posta atın: eslemnur_notes@proton.me

## Kapsam
Bu politika şu bileşenleri kapsar:
- Diyanet API entegrasyonu
- Service Worker (PWA)
- Kullanıcı verisi işleme (local storage)

## Bildirim Sonrası
- Sorunu aldığınızı 48 saat içinde onaylarım
- Düzeltme için makul süre tanırım
- Fix yayınladığınızda sizi credits'de isimlendirebilirim

## Kapsam Dışı
- Üçüncü parti API'lerin (Diyanet, vb.) kendi güvenliği
- Kullanıcının kendi cihazındaki local storage yönetimi
- Tasarım tercihleri veya UI hataları

## Sorumlu Bildirim İlkeleri
- Lütfen çalışan exploit kodları paylaşmayın
- Hakkında şüphelendiğiniz hassas verileri test etmeyin
- Bildirim süreci sırasında gizliliğe saygı gösterin

## Not
Bu proje akademik ve kişisel amaçlıdır. Kritik production sistem değildir. Ancak kullanıcı deneyimini korumak için güvenlik açıklarını önemsiyorum.
